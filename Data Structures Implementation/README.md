# Task 1 - Data Structures Implementation

## Implemented Data Structures

- Singly Linked List
- Stack

Both implementations support insertion, deletion/pop, search, and display operations.

## Compile

```bash
gcc linked_list.c -o linked_list
gcc stack.c -o stack
```

## Run

```bash
./linked_list
./stack
```

On Windows:

```bash
linked_list.exe
stack.exe
```

## Complexity

### Linked List

| Operation | Complexity |
|---|---|
| Insert at end | O(n) |
| Delete | O(n) |
| Search | O(n) |
| Display | O(n) |

### Stack

| Operation | Complexity |
|---|---|
| Push | O(1) |
| Pop | O(1) |
| Search | O(n) |
| Display | O(n) |
