# InternSpark C/C++ Programming Tasks

This repository contains four separate solutions for the InternSpark C/C++ Programming task.

## Tasks

1. Data Structures Implementation
2. Algorithms & Problem Solving
3. System Programming / File I/O
4. C++ OOP & STL Mini Application

## Requirements

- GCC / G++
- C standard compiler
- C++17 compiler for Task 4
- Make (optional for Task 4)

## Repository Structure

```text
InternSpark-C-CPP-Tasks/
├── README.md
├── Task1_DataStructures/
├── Task2_Algorithms/
├── Task3_FileIO/
└── Task4_CPP_OOP/
```

Each task has its own README with compilation, execution, sample output, and complexity information.
